## Features

- **two full themes, not one** — `ayoub Theme Dark` and `ayoub Theme Light`, both
  first-class. the light one is a real palette, not an inverted dark one.
- **the whole workbench is themed**, not just the editor. tabs, sidebar, status
  bar, activity bar, terminal, minimap, git decorations, peek view, quick pick,
  notifications, breadcrumbs, scrollbars.
- **304 / 303 workbench colors** and **247 token rules** per theme, built
  role-for-role so dark and light feel like the same theme.
- **semantic highlighting enabled** in both, with overrides for `enumMember`,
  `variable.constant` and `variable.defaultLibrary`.
- **low contrast on purpose.** accents are muted so long code doesn't get
  visually loud, but every token still clears WCAG AA against its background.
- **diff, markdown, git and terminal colors** all match the palette, so a merge
  conflict doesn't turn into a rainbow.
- **works with every language** — the token rules cover JS/TS, Python, Rust,
  Java, C/C++, CSS/SCSS/LESS, Go, Ruby, PHP, Haskell, Elixir, Unison, JSON, YAML,
  XML, Markdown, and generic TextMate scopes for everything else.

## Install

1. open the Extensions view (`Ctrl+Shift+X` / `Cmd+Shift+X`)
2. search **ayoub Theme**
3. click install
4. `Ctrl+K Ctrl+T` (or `Cmd+K Cmd+T`) and pick **ayoub Theme Dark** or
   **ayoub Theme Light**

to flip between dark and light without leaving the editor, tie it to your OS
with **Preferences: Color Theme** in settings, or just use the command above.

## Requirements

VS Code `1.82.0` or newer. no dependencies, no settings to configure, no
`workbench.colorCustomizations` needed.

## Keyboard shortcuts

useful ones if you needed them ._. :

- split editor — `Ctrl+\` (`Cmd+\` on macOS)
- toggle preview — `Ctrl+Shift+V` (`Shift+Cmd+V` on macOS)
- command palette — `Ctrl+Shift+P` (`Cmd+Shift+P` on macOS)
- change color theme — `Ctrl+K Ctrl+T` (`Cmd+K Cmd+T` on macOS)
- quick open file — `Ctrl+P` (`Cmd+P` on macOS)

for more, see VS Code's [keyboard reference](https://code.visualstudio.com/docs/getstarted/keybindings).
